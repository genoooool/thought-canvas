## 1. 本次验证对象

v12.6 保留 v12.5 的分支、推理、标注、多语言、编码修复和 Codex 能力，并增加第三条主线：

1. **设置内的简体中文、English、日本語界面切换**；
2. **历史文本乱码的识别、保守修复、备份与迁移审计**；
3. **确定性的语义列自动排布：拆解同列竖排、后代向右、完整子树纵向避让**。

同时完整回归复杂 Markdown 选区、递归拆解/提炼、消息级分叉、上下文快照、推理对象、比较决策、流式停止续写、API Key 模型同步、思考等级、Codex OAuth/动态模型/命名只读权限、版本恢复、标注、折叠和三种导出。

## 8. 测试边界

- Chromium 套件使用真实 HTML/CSS/JavaScript；受执行环境限制，浏览器网络层使用同构页面内 API。真实 Node HTTP、文件系统、会话令牌和密钥隔离由独立本地集成测试覆盖；
- Codex 自动化使用严格的 App Server JSONL 替身，不等同于真实账号、套餐、组织策略、网络或模型灰度；
- 普通模型供应商使用带认证的本地假上游，没有使用用户真实 API Key；
- 乱码类型可由字符串特征判断，但最初入口仍需原始损坏文件或上游原始日志才能精确归因；
- 不可逆丢字、替换字符或非 Windows-1252 的复杂损坏无法保证自动恢复；迁移前备份用于人工取证和恢复。
