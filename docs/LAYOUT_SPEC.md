# v12 画布布局与视觉节奏

## 1. 坐标与树布局

画布从左到右。兄弟节点组按子树高度围绕父节点垂直中心排列；新增兄弟后整组重算，不把新节点塞进偶然空隙。

## 2. 聚焦规则

- 单节点：完整进入视口并保留合理边距；
- 分支：同时展示来源节点和新节点；
- 拆解：展示来源节点与本次新建模块组；
- 汇总：展示来源选择与汇总节点；
- 用户已主动平移后，系统只在明确创建/定位动作时改变视口。

## 3. 画布导航

- 搜索定位时聚焦目标；
- 当前路径模式显示根—当前路径、直接下一步和相关 merge 来源；
- 小地图按可见世界坐标缩放，标出当前视口；
- “适配全部”是用户主动动作，不代替新节点的局部聚焦。

## 4. 分组和碰撞

`answer`、`decomposition`、`merge` 使用独立 groupId；组间距大于普通节点间距。归档节点不参与可见碰撞计算。自动布局只改坐标，不改语义关系、消息或顺序。

## 5. 连线

- 默认曲线，可切换直角线；
- 默认实线，可切换虚线；
- 用户虚线：`3 3`，圆角线帽；
- 处理中虚线：`4 3`，带缓慢流动动画；
- 分支、拆解、merge 使用 relation 标签和不同语义类；
- JSON Canvas 导出把这些关系转换为带 label 的边。

## 6. 网格与尺寸

- 主画布点阵：14px；
- 节点布局宽度：约 308px；
- 内容高度在最小 170px 与最大 224px 之间估算；
- 右侧栏宽度可在 360–680px 之间调整；
- 顶部网格在 1320px 以下改为两行。

## 7. 无重叠标准

浏览器 gate 对以下矩形执行两两碰撞断言：顶部可见区块、侧栏动作、所有未归档节点。布局完成后还验证唯一子节点与父节点中心对齐、平行兄弟围绕中心对称。
