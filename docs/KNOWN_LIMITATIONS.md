# Thought Canvas v12.5 已知限制

1. **真实云模型未纳入本地 PASS**：账号、余额、网络、限流、地区和模型灰度由用户环境决定。测试使用本地假上游或测试替身。
2. **模型目录不统一**：兼容供应商可能没有 `/models`、返回非标准字段或隐藏账号权限。此时使用手动模型回退；能力可能标记为 `inferred`。
3. **能力推断不是供应商保证**：未声明思考等级时会根据协议和模型名推断。供应商实际拒绝某参数时，应切换为“自动”或在高级设置中禁用思考参数适配。
4. **精确 token 仍为估算**：上下文检查器未为所有模型集成官方 tokenizer。
5. **Codex 依赖本机 CLI/App Server**：未安装、版本过旧、账号策略限制或官方授权页面不可达时无法连接。Thought Canvas 不提供私有 Token 回退。
6. **Codex 模型可能随账号变化**：套餐、工作区策略和灰度会改变 `model/list`；重新连接或刷新状态后选择器会更新。
7. **浏览器 E2E 网络边界**：测试环境不允许 Chromium 访问 localhost，因此 UI 使用真实前端代码和同构页面内 API；真实 HTTP 与文件由 Node 套件覆盖。
8. **翻译以产品 UI 为范围**：英文和日文覆盖应用界面、动态状态、常用弹窗及请求语言指令，不会自动翻译项目标题、用户输入、模型回答、标注或推理对象。用户内容需要模型或用户主动翻译。
9. **第三方/模型名称保持原名**：供应商品牌、模型 ID、账号套餐名和部分上游错误信息可能保持供应商原文，以避免误改专有名词。
10. **新增文案需要同步词典**：应用没有构建期 ICU/编译器；后续新增中文 UI 文案时，应同时补充 `i18n.js` 和 `tests/i18n-test.mjs`/浏览器覆盖。

12. **乱码修复故意保守**：只有转换后乱码信号显著下降时才自动修复。模糊样本可能保持原样，避免把合法法语、西班牙语、德语或专有名词错误转换。
13. **不可逆丢字无法恢复**：若历史链路已经把字符替换为 `�`、删除字节或发生非 Windows-1252 的多重转换，单靠当前字符串可能无法完整复原。项目自动迁移会先保留原始备份。
14. **没有发送前逐区块上下文开关**：当前可审计上下文，但还不能临时关闭单个区块。
15. **单进程文件模型**：原子写入与备份面向单个服务进程；多进程并发没有文件锁或冲突合并。
16. **版本不是完整事件溯源**：最多 20 个常规快照，高频流式中间保存不创建版本；编码迁移前备份也受目录清理策略约束。
17. **选区偏移使用 UTF-16 code unit**：外部工具对复杂 Unicode 可能采用不同索引；应用内部可稳定回溯。
18. **JSON Canvas / Markdown 是导出层**：只有 Thought Canvas JSON 能无损保留上下文快照、生成记录和 Compact。
19. **分支比较目前为双节点**：尚无多方案矩阵和自动差异高亮。
20. **推理关系由用户确认**：系统不会自动把模型陈述当成已验证证据。
21. **无多人协作和云同步**：当前定位为本机单人工作台。
22. **完整无障碍审计尚未完成**：字号和焦点已改善，但仍需屏幕阅读器、对比度、缩放与键盘全流程审计。
23. **画布仍为自研 DOM/SVG**：超大图、触控和多人协作可能需要成熟画布引擎。
24. **标注不是自由形状编辑器**：当前提供固定卡片、标题、正文和五类语义；尚不支持任意形状、图片、手绘、连接任意两个节点或多端点连线。
25. **折叠是本地可见性状态**：当前没有为不同视图保存独立折叠方案，也没有按层级批量折叠。
26. **复杂选区允许范围未知**：当可见文本无法唯一映射到原始 Markdown 时，系统会保留文字并把偏移记为 `-1`；这保证操作可继续，但外部审计只能回到消息级来源。
27. **Codex 权限配置目录依赖 App Server**：现代版本必须返回允许的 `:read-only`。组织策略禁用或目录缺失时，Thought Canvas 会拒绝生成；不会自动提升到 workspace-write/full-access。
28. **真实 Codex 需用户侧烟雾测试**：发布环境没有真实 Codex CLI 与账号，自动化以严格协议替身验证，不能替代用户机器上的最终调用。
